# Registro de Personas

Aplicación de consola en Python para gestionar un registro de personas
(agregar, listar, buscar y eliminar). Los datos se guardan en un archivo
local `personas.json`.

## Requisitos

- Python 3.8 o superior

## Cómo clonar el proyecto

```bash
git clone <URL-DEL-REPOSITORIO>
cd registro-personas
```

## Cómo ejecutar

```bash
python3 registro.py
```

Se mostrará un menú interactivo con las opciones:

1. Agregar persona
2. Listar personas
3. Buscar persona por nombre
4. Eliminar persona por id
5. Salir
